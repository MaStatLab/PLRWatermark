# Selected historical alternate-prior inference records

Only four historical inference-summary JSON files are included in this
directory, to support `code/test_delong_prompt_bootstrap.py`. They retain the
explicit `historical_non_inferential` status and are not valid evidence for
the current manuscript's inferential statements.

The current paired prompt-cluster bootstrap results are in
`../bayesian_paper_benchmark/real_model/temperature_matched/delong_tests_bootstrap.json`
and `delong_tests_holdout.json`. No current inverse-transform inference is
claimed. This partial historical directory is not a full alternate-prior
replication package; its old full-project provenance and unrelated results
are deliberately not copied.
